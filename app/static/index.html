How It Works

                    
Architecture & Pipeline

                    
A 10-stage ML pipeline with proper cross-validation, calibration, and explainability.

                


                
                

                    

                        
1

                        

                            
Data Generation

                            
9,000 orders with realistic noise. 22.6% return rate — genuinely imbalanced.

                        

                    

                    

                    

                        
2

                        

                            
EDA & Leakage Check

                            
Class balance, distributions, correlation audit. No feature > 0.17 correlation with label.

                        

                    

                    

                    

                        
3

                        

                            
Feature Engineering

                            
Leakage-free transforms: delivery mismatch, interaction terms, target encoding (fit on train only).

                        

                    

                    

                    

                        
4

                        

                            
Model Selection

                            
5-fold CV across 3 families: Logistic Regression, Random Forest, LightGBM. LR won on PR-AUC.

                        

                    

                    

                    

                        
5

                        

                            
Imbalance Handling

                            
class_weight='balanced' beat SMOTE/SMOTE-Tomek. Simpler wins when margin is < 0.005 PR-AUC.

                        

                    

                    

                    

                        
6

                        

                            
Cost-Based Threshold

                            
₹50 FP / ₹350 FN cost model → T=0.14 (not 0.5). 13.3% cost reduction vs naive.

                        

                    

                    

                    

                        
7

                        

                            
Isotonic Calibration

                            
Raw probs were rank-ordered but inflated. Isotonic cut calibration gap 89.7%.

                        

                    

                    

                    

                        
8

                        

                            
SHAP Explanations

                            
Per-decision attribution. Template-based sentences from real log-odds — not LLM hallucinations.

                        

                    

                    

                    

                        
9

                        

                            
Robustness Checks

                            
Leakage audit, 4 stress tests, 3-seed stability. Bug found & fixed during demo prep.

                        

                    

                    

                    

                        
10

                        

                            
FastAPI Serving

                            
Live scoring with calibrated model. SHAP explains each decision in real time.

                        

                    

                


                
                

                    
Key Design Decisions

                    

                        

                            
🎯

                            
Why Logistic Regression?

                            
The DGP is log-odds-linear with interaction features already materialized — this removes trees' usual structural advantage. LR won on CV PR-AUC and is fully interpretable.

                        

                        

                            
📐

                            
Why Isotonic Calibration?

                            
class_weight='balanced' inflates predicted probabilities. Isotonic recalibration makes "30% score ≈ 30% observed return rate" true — verified, not assumed.

                        

                        

                            
🐛

                            
The Bug We Found

                            
High-value threshold was recomputed per API call (quantile of 1 row = that row). Silently zeroed new_account_x_high_value. Caught during demo, fixed, regression test added.

                        

                        

                            
💰

                            
Why Not 0.5 Threshold?

                            
Missing a return (FN) costs 7× more than a false flag (FP). The cost-optimized T=0.14 catches 81% of returns instead of ~30% at T=0.5.
